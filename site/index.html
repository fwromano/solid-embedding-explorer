What this picture shows · data and projection methods

All-row PCA is newly fitted to combined real rows. Original five-solid balanced PCA and semantic fits stay immutable; new shapes projected out of cohort for those fits. PLS is refitted on all 94,200 views across ten shapes, with equal total weight for every shape/paint pair. It is an exploratory fit with no held-out accuracy claim. Semantic shape/color axes are class-mean SVD fitted only on balanced TRAIN headings 0° and 20°. These supervised displays are not held-out accuracy, text similarity, or calibrated confidence. Prefixes are renormalized before fitting and exact cosine comparison.

Views include measured rows and explicitly labeled symmetry repeats. Each repeat references the original embedding, image and projection coordinates. Identical copies overlap; every visible copy contributes equally to the blended viewpoint color at its source position. The inspector swatch shows the selected view’s individual color. Playback moves the inspection marker without changing the cloud. Clicking a source point selects its visible copy nearest the requested heading. Ideal continuous heading aliases approximate finite-mesh appearances. A sphere has a full rotational alias: heading and elevation are not independently observable, even though actual elevation images are retained. Binary projection coordinates follow source catalog order; the source row ID is not an array offset. Heading paths connect views at a fixed elevation (1° sampling); elevation paths connect views at a fixed heading (5° sampling). Both stay within the same shape and paint, follow visible filters, and can be enabled independently. Repeated symmetry links are drawn once. Dashed links bridge filtered gaps and the heading seam; elevation paths stop at the lowest and highest visible elevations without wrapping. Display filters never refit axes. An explicit build refresh may change PCA-all.

White outline marks the inspected row; a dashed crosshair identifies an occluded point. The image and inspection marker share a view ID; the underlying plot position may represent several symmetry views of the same source row. Source images have their original neutral background; symmetry repeats reuse these source images. No new elevations or camera rolls are inferred.

The mapping repeats source indices for every symmetry view. Use source_index to repeat rows from any original embedding prefix or projection array. Neighbor search and fitted axes use the measured source rows once.

PLS is weighted multi-target regression on shape and paint one-hot blocks and/or observable pose contrasts. Each shape/paint pair receives 1/60 of the total weight, and each included target block has equal weighted variance. Heading uses sin/cos of the symmetry-aware canonical phase where observable; elevation uses sin/cos where observable. Unobservable coordinates receive zero centered contrast: cylinder, cone and torus supply no heading signal, and sphere supplies no pose signal. All 94,200 existing embeddings contribute; these latent variables are exploratory display axes, not held-out accuracy or PCA percentages. Plot colors still use physical heading, not canonical pose phase.
